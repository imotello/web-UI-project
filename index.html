HTML web page example 1

this is an exmple of a simple HTML web page that shows profile
of a professional camel.


here is how the camel profile is designed in HTML:


1. Container- The complete HTML web page is wrapped in a container. The container is a div elememnt with the class container.

2. Header- Inside the container, we have a header element that contains a logo and the navigation menu.

3.Aside- Asside contains the profile picture and other navigation links.

4. Main- The main element contains the profile information. Like the name, the career, the skills, the contact form,etc.

5. Footer- The footer element contains the copyright information.
